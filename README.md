# WordPress-AllinOne-basic

✅ Features:
🔒 Security & Backup
Basic firewall (blocks malicious query strings)

Simple malware scanner (scans theme/plugin files for common malware patterns)

One-click backup of database and wp-content directory

⚙️ Performance & Optimization
GZIP compression

Image compression

Minify HTML, CSS, and JS

📈 SEO & Indexing
Sitemap generator

robots.txt generator

Basic SEO meta tags like Yoast

🛠 Admin Panel
Toggle each feature from WordPress Admin under Settings → Site Optimizer
